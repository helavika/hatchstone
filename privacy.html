The short version

Hatchstone has no accounts, no ads and no analytics. Your nest is saved on your own device, and nobody else sees it.

What is stored, and where

  • On your device: your nest (glowlings, progress, settings) in the browser's local storage, and the game's files for offline play. You can make a backup code in the menu and delete everything by clearing the site's data.
  • In Telegram: if you play inside Telegram, a copy of your nest is also kept in Telegram's cloud storage for this game, so it follows you between devices. Only this game can read it.
  • A log of errors: if the game runs into an error, a short note about it is kept on your device. It only leaves your device if you choose to send feedback.

Playing together

To connect two phones, the game uses a public matchmaking server (PeerJS) and a STUN server (Google) only to find a direct route between the two devices. After that, the shared egg's taps go straight from one device to the other. No nest data is sent to those servers.

Feedback

Feedback is never sent by itself. When you choose to send it, the game opens a GitHub page with your words and some technical details (device, language, screen size, recent errors) for you to check before sending.

Hosting

The game is hosted on GitHub Pages. Like any website, GitHub may keep standard server logs (such as IP addresses) for security. See GitHub's privacy statement.

Children

The game collects no personal information from anyone, children included.

Questions

Open an issue on GitHub.

Коротко

У Hatchstone немає акаунтів, реклами й аналітики. Твоє гніздечко зберігається на твоєму пристрої, і ніхто інший його не бачить.

Що зберігається і де

  • На твоєму пристрої: гніздечко (глоулінги, прогрес, налаштування) у локальному сховищі браузера, а також файли гри для роботи без інтернету. У меню можна зробити код резервної копії, а видалити все — очистивши дані сайту.
  • У Telegram: якщо граєш у Telegram, копія гніздечка зберігається ще й у хмарному сховищі Telegram для цієї гри, щоб переходити з тобою між пристроями. Прочитати її може лише ця гра.
  • Журнал помилок: якщо в грі стається помилка, коротка нотатка про неї лишається на пристрої. Вона залишає пристрій, лише якщо ти вирішиш надіслати відгук.

Гра вдвох

Щоб з'єднати два телефони, гра використовує публічний сервер для знайомства пристроїв (PeerJS) і STUN-сервер (Google) — лише щоб знайти прямий шлях між ними. Далі удари по спільному яйцю йдуть напряму з пристрою на пристрій. Дані гніздечка на ці сервери не надсилаються.

Відгуки

Відгук ніколи не надсилається сам. Коли ти вирішиш його надіслати, гра відкриє сторінку на GitHub із твоїм текстом і технічними деталями (пристрій, мова, розмір екрана, останні помилки), щоб усе можна було перевірити перед відправкою.

Хостинг

Гра розміщена на GitHub Pages. Як і будь-який сайт, GitHub може зберігати звичайні журнали сервера (наприклад, IP-адреси) з міркувань безпеки.

Діти

Гра не збирає жодних персональних даних ні в кого, зокрема в дітей.
